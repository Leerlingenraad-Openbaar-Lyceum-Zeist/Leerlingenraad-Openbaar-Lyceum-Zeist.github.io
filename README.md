# LLR OLZ website
Statische website voor de Leerlingenraad van het Openbaar Lyceum Zeist.

## GitHub Pages
1. Zet alle bestanden in een GitHub-repository.
2. Ga naar **Settings → Pages**.
3. Kies **Deploy from a branch**.
4. Kies `main` en `/ (root)`.
5. Opslaan. GitHub Pages publiceert de site.

Geen build step nodig: alleen HTML, CSS en JavaScript.

De Schoolwiki-link en contactgegevens staan in de HTML en kunnen eenvoudig worden aangepast.
